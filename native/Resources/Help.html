Galileo Gallery

A native Mac studio for arranging images and video into motion.

Make a gallery

Add media with File → Add Media, or drop files into the window. Select and reorder media in the sidebar. Use the Media inspector to fit, crop, caption or replace a source. Excluded media stays in the document but not the output.

Choose Scene in the toolbar. Families group related compositions; variants keep their own motion. Scrub to compare them using the same media. Cancel leaves the document untouched. Apply is one undoable edit.

Centre spotlights and looping video

Select a slide in Media and enable Bring to centre. Set Hold and Size. The slide moves forward, holds at the centre, returns to its route and lets the sequence continue. Each marked slide keeps its own settings. Spotlight holds add to the motion duration and are included in export.

For video, leave Play source and Loop source enabled. A short clip can repeat inside a longer centre hold. Rate and In/Out affect the clip independently. Editor Pause freezes the current composition and source time; an authored centre hold keeps source video playing. Exported movies are silent.

Playback

The timeline uses exact frame indices. The frame field supports precise inspection. Space plays or pauses when the canvas has focus; arrow keys step one frame. Once exports one cycle. Repeat exports the chosen number. Loop previews continuously and exports one cycle.

Save and recover

Galileo documents contain managed copies of their original media. Moving an imported source outside the app does not break a saved document. Use native Save, Save As and Revert commands. Autosave is managed by macOS. A failed save is an error, never a success badge.

Legacy ZIP-based Galileo projects open as separate native copies. Their source media and original manifest are preserved. Native motion is reauthored and is not an identical legacy render; review before exporting. Older unknown schemas are rejected without modifying the original.

Export

Choose H.264 MP4, ProRes 422 MOV, ProRes 4444 MOV, a PNG still or a PNG sequence. Transparent output requires ProRes 4444 or PNG. Video is silent and tagged Rec.709; PNG uses sRGB. Preserved legacy audio is not played or exported in this build.

Exports run independently of a document window. Open Window → Exports to see progress, cancel or reveal the result. An existing movie is replaced only after a new output succeeds. PNG sequences always use a new folder. There is no automatic poster sidecar to overwrite.

Controls and limits

The inspector shows controls supported by the chosen variant. Composition settings, media framing, source playback and export settings are separate. Scene presets save composition and timing, not media. Interface appearance never changes artwork.

Native decoding depends on the codecs supported by your Mac. This build supports up to 512 media entries, 512 MB per source, 4 GB of managed media and a 33-megapixel canvas. Video exports are limited to 216,000 frames. These are conservative resource guards, not performance promises.

Distribution

Requires macOS 14 or later on Apple silicon. This build is ad-hoc signed, not Developer ID signed or notarized. Keep downloaded checksums and release provenance with the app. GPL-3.0 and source notices are included in the bundle.
