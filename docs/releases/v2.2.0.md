# Galileo Gallery 2.2.0

Native Drift backgrounds for Apple silicon and macOS 14 or later.

- Imports all 72 named Drift studies across Solid field, Gradient weather, Luminous aura, Printed matter, Darkroom void, Cutting map, Quiet grid, Tidal wave and Atelier, with all 28 palettes.
- Native Metal shader adaptation, not a browser embed or replacement gradient approximation. Original shader source, defaults and credit are preserved.
- Background browser with static, lazy thumbnails, family filter and search. Independent palette, colour, intensity, motion, grain, vignette and variation controls. Cancel leaves the document unchanged; applying a background is undoable.
- Frame-based animation repeats on each complete scene cycle, including spotlight holds. Pause, scrubbing, repeat and export use the same frame identity. Turning off Animate background freezes both motion and finishing grain without freezing source videos.
- Precompiled shipping shaders, one shared kernel, preview-sized processing, and bounded static thumbnails. No extra wall-clock animation loops.
- Existing 2.1 solid, gradient and transparent canvases retain their exact parameters through in-memory migration. New documents save schema 6; keep originals before saving an upgrade. The scene preset library remains scene-only.

## Use the backgrounds

In the right inspector, choose **Scene → Canvas → Background → Drift**. Pick a study and select **Use background**. **Browse…** changes the study later. Adjust the palette and motion below it; expand **Colour and texture** for custom colours, grain, vignette and variation.

Choosing a background does not alter media, scene or spotlight settings. Sound remains absent by design. Drift itself was not modified.

## Export colour correction

The new decoded-movie comparison exposed a pre-existing mismatch between Core Graphics' named BT.709 ICC profile and the HDTV transfer curve reconstructed from the movie's colour tags. The encoder now receives pixels rendered in the colour space derived from those same tags, with matching buffer attachments. The original pixel comparison tolerances remain unchanged.

## Validation and limits

The native adaptation retains upstream procedural equations, but does not claim pixel-identical WebGL/Metal output across hardware. Grain uses logical output coordinates so changing the preview size does not redefine its texture scale. Higher-density paper and line details can alias at small preview sizes. Upstream motion is retained; repeat determinism is not a guarantee that every study has an imperceptible loop seam.

The release uses Mac build, package and document/export validation, plus catalogue/migration/clock, rendered-family, transparency/colour and independently decoded-movie background checks. All 72 shipping backgrounds are rendered from the precompiled kernel in the packaged application. Synthetic captures are included with the build evidence. Broader hardware and long-session performance guarantees are not claimed.

## Install and compatibility

Quit Galileo, open **Galileo.Gallery-2.2.0-macOS-arm64.dmg**, drag Galileo Gallery to Applications and choose Replace. Eject the DMG and launch from Applications.

Keep copies of important projects: a 2.2 save uses schema 6, which 2.1 and 2.0 cannot read. Existing projects are migrated in memory when opened. Imported originals remain intact.

The application is ad-hoc signed, not notarized. Use Apple's per-app Open Anyway path only for a trusted developer-verification warning. Do not disable Gatekeeper globally or bypass a damaged/malware warning.

Original Galileo sources retain GPL-3.0 terms; adapted Drift catalogue/shader files retain AGPL-3.0-or-later. Both licenses, source provenance and offline build instructions are included.
