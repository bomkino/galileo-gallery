# Galileo Gallery 2.2.0

Native Drift backgrounds for Apple silicon and macOS 14 or later.

- Imports all 72 named Drift studies across Solid field, Gradient weather, Luminous aura, Printed matter, Darkroom void, Cutting map, Quiet grid, Tidal wave and Atelier, with all 28 palettes.
- Native Metal shader adaptation, not a browser embed or replacement gradient approximation. Original shader source, defaults and credit are preserved.
- Background browser with static, lazy thumbnails, family filter and search. Independent palette, colour, intensity, motion, grain, vignette and variation controls.
- Frame-based animation closes once per complete scene cycle, including spotlight holds. Pause, scrubbing, repeat and export use the same frame identity. Animate background freezes both motion and finishing grain without freezing source videos.
- Precompiled shipping shaders, one shared kernel, preview-sized processing, and bounded static thumbnails. No extra wall-clock animation loops.
- Existing 2.1 solid, gradient and transparent canvases retain their exact parameters through in-memory migration. New documents save schema 6; keep originals before saving an upgrade. The scene preset library remains scene-only.

Use Scene → Canvas → Background → Drift → Browse. Choosing a background is undoable and does not alter media, scene or spotlight settings. Sound remains absent by design. Drift itself was not modified.

The native adaptation retains upstream procedural equations, but does not claim pixel-identical WebGL/Metal output across hardware. Grain uses logical output coordinates so changing the preview size does not redefine its texture scale. Higher-density paper and line details can alias at small preview sizes.

The release uses existing Mac build, package and document/export validation, plus catalogue/migration/clock, rendered-family, transparency/colour and decoded-movie background checks. Synthetic captures are included with the build evidence. Broader hardware and long-session performance guarantees are not claimed.

The application is ad-hoc signed, not notarized. Quit Galileo, open the arm64 DMG, drag to Applications and choose Replace. Eject the DMG and launch from Applications. Use Apple's per-app Open Anyway path only for a trusted developer-verification warning.
