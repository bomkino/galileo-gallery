# Galileo Gallery 1.2.0

A complete interface-colour release. Scene engines, media, Project data, Timeline behaviour, and deterministic export remain unchanged.

## Added

- A native-feeling Light / Dark control in both the Scene catalogue and studio.
- First-run operating-system preference, local persistence, cross-window storage synchronisation, and matching application theme colour.
- Dedicated warm dark palette rather than colour inversion.
- Separate Phosphor-derived select carets for light and dark surfaces.
- Forced-colour, increased-contrast, reduced-transparency, and reduced-motion fallbacks.

## Hardened

- Theme changes preserve titlebar, panel, stage, card, and action geometry with no layout shift.
- Theme preference remains local interface state and never enters `.galileo` Projects, Scene settings, Timeline state, or export requests.
- Hidden export renderers use the neutral existing colour boundary rather than a user-interface preference.
- G08 now verifies both modes, system fallback, persisted reload, storage synchronisation, contrast, focus visibility, menu treatment, clipping, and Project invariance.
- Production dependencies are audited separately from development-tool transitive dependencies before packaging.
