# Galileo Gallery 2.3.0

Media, timing and editing update for **Apple silicon / macOS 14 or later**. The app stays native, local and silent.

## Included

- Still and animated WebP import with alpha/orientation and representative partial-frame animation checks.
- SDR VP8/VP9 WebM intake, including transparent VP9 and variable frame timestamps. Bundled local FFmpeg/libvpx prepares a native working copy; the original remains unchanged. No Homebrew, browser or conversion service is needed.
- On-demand silent source preview and filmstrip with trim, Reset trim, rate, loop and Freeze here. Apply is undoable; Cancel leaves the project unchanged.
- Background audition on the actual composition, retained custom settings when reselecting a study, and an option to keep the palette. Existing 72 Drift backgrounds and 28 palettes remain.
- Live appearance editing, time-preserving frame-rate changes, temporary spotlight audition, stable inspector context, consistent crop-ratio constraints and a filled-frame preview.
- Ordered per-file import outcomes, stale drop/import protection, clearer export progress and queue completion tied to its snapshot.

## Corrected

Opening selection now survives Reverse. Repeat closing holds sample the intended final pose. Short Reel/Wave routes keep visible source positions continuous. Writer and reader enforce the same actual encoded-manifest limit. Recovery retains intact PDF page imagery when only its archived PDF is missing. Ordinary scene choices do not inherit timing from a previously browsed named preset. Failed/cancelled work cannot adopt results into a different document.

## Performance work

Sequential video readers reuse source frames for the interval they cover instead of seeking for every output tick. Animated timing is indexed. Image preparation follows projected size and crop magnification. Core Image handles crop/masks/reveals/fragments without a full CPU bitmap per fragment. Readers/caches are bounded; memory pressure clears reusable resources; minimized windows stop scheduling new preview work. Gesture undo keeps one before-state, and progress updates are throttled.

These remove identified repeated work. The release evidence records the hosted Mac and measurements; it is not a promise of smooth playback for every collection or an M2/M1 physical-device benchmark.

## Validation

Targeted regressions cover WebP pictures/timing, WebM alpha/VFR/persistence, frame reuse, project/recovery limits and the identified timing cases. The packaged application imports transparent WebM plus animated WebP, saves/reopens them, authors an eight-second spotlight, exports after the editor closes and independently decodes all 192 frames. The loop, preview/output comparison and absence of audio are checked. The earlier document/autosave/export journey and all 72 shipping background renders remain.

The final attached validation record contains the actual tested commit, machine, results and synthetic captures. Compilation and passing tests are not a claim that every possible bug is fixed.

## Install and limits

Quit Galileo normally, keep copies of important projects, open **Galileo.Gallery-2.3.0-macOS-arm64.dmg**, drag the app to Applications and choose Replace. Eject the image and launch from Applications. [Installation](https://github.com/bomkino/galileo-gallery/blob/v2.3.0/INSTALL.md).

A new save uses schema 7. Older native documents migrate in memory; earlier apps cannot read a 2.3 save. WebM originals and native working copies are both stored; working copies can be much larger. Originals have a 512 MiB/file and 4 GiB unique-source budget; working copies have separate 4 GiB/file and 16 GiB aggregate limits.

**Not included:** AV1/HDR WebM intake, WebM output, sound, HDR mastering guarantees, new halation/lens effects, A/B comparison or an automatic updater. Those optional effects were not needed to fix the working application. Human accessibility, long-session and broader physical-hardware acceptance remain separate work.

The app is ad-hoc signed, **not notarized**. For a trusted developer-verification warning, use Apple's per-app Open Anyway process. Never disable Gatekeeper globally or override a damaged/malware warning.

This software uses FFmpeg under LGPL-2.1-or-later and libvpx under its retained license. The matching **codec-source ZIP** supplies original source, configuration, licenses and build instructions alongside the app. Drift source provenance and credits remain; Drift itself was not changed.
