# Galileo Gallery 2.4.0 — prerelease

Native Studio editing and exact Still selection for Apple silicon, macOS 14 or later.
This is a prerelease: physical-device, VoiceOver, minimum-OS and broader media/performance acceptance remain open. The previous stable release remains the default download.

## Changes

- Native media-rail drag with selection preserved and one-step undo/redo.
- Video/Animation and Still controls. Still remembers First, Middle, Last or a custom source frame; trim, rate and loop survive display-mode changes.
- Exact source presentation intervals for still selection, with bounded shared decoding, independent cancellation and source preview before Apply.
- Older native documents open as protected upgrade copies. Original files are preserved; schema 8 saves require a separate destination. Failed saves retain edits.
- Shared native controls, richer dark surfaces and the pinned pitch.dog typography across the editor, inspector and sheets. The canonical UI package is pinned to `8f296630180ea4dbc77fe65a9c86e88a5b9bb9c0` in [pitchdog-studio-ui](https://github.com/bomkino/pitchdog-studio-ui).

## Validation and limits

The release workflow tests native contracts, exercises saving, reopening, playback and export in the packaged app, and performs the actual drag, menu, keyboard and source-selection journey. It verifies the DMG and ZIP against the built app; attached evidence records the exact source, package revision and hosted Mac.

Hosted checks do not establish M2 8 GB performance, physical trackpad behavior, VoiceOver acceptance, offline acceptance or every media edge case. These remain open before stable promotion. Existing local-only media behavior and silent exports remain.

Keep original projects. Schema 8 documents cannot be opened by older releases. This build is ad-hoc signed and not notarized. The matching codec-source archive and retained license notices accompany the app.
