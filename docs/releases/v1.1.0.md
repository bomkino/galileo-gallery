# Galileo Gallery 1.1.0

A focused interface-system release. The 29 Scene engines and deterministic export boundary remain intact; the studio around them is cleaner, more consistent, and easier to operate.

## Changed

- Adopted the public pitch.dog type system as the packaged default: `PD Head`, `PD Body`, `PD Body Alt`, and `PD Eyebrow`.
- Replaced hand-authored product-control SVGs and Interface Scale glyphs with Phosphor icons.
- Normalised panel, card, control, menu, form, Scene-browser, and responsive spacing onto a 4 px token scale.
- Preserved a minimum 44 px target across Interface Scale settings.
- Added runtime and source verification for font binaries, font resolution, icon provenance, spacing contracts, clipping, reachability, keyboard navigation, and canvas geometry.
- Reorganised documentation around active product docs while retaining the full programme evidence archive.
- Added an exact-version release workflow that builds and tests macOS, Windows, and Linux packages before publication.

## Source anchors

- pitch.dog type system: `bomkino/pitchdog-type-system@786b4a2b671182319320f922b8de8f927ea3a002`
