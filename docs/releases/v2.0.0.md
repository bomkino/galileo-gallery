# Galileo Gallery 2.0.0

A native Mac release for **Apple silicon and macOS 14 or later**. This replaces the old cross-platform application as the active product line.

## Included

- AppKit/SwiftUI document windows, native menus, conventional Play/Pause and frame stepping.
- Shared native composition for preview and H.264/ProRes/PNG output, with Core Image and Metal where available.
- Per-slide **Bring to centre**, adjustable **Hold** and **Size**, and return to the sequence.
- Looping videos inside spotlight holds; source playback, rate and trims remain independent of scene travel.
- Project-contained original media, undo/redo, scene audition, native save/autosave and separate-copy legacy migration.
- Scene families and variants instead of a flat scene-count target.

## Reliability corrections

Document content transactions notify native save tracking exactly once. Preview rendering coalesces requests rather than cancelling every playback tick. Export frame counts and durations include spotlights; still-frame time survives frame-rate changes. Exports check current destination identity before replacing a file and verify decoded movie timestamps/frame count. Cancelled imports cannot adopt stale results into another document state.

The spotlight video test now declares the synthetic fixture's Rec.709 colour space explicitly. Its original pixel assertions are retained; no tolerance was raised to obtain a pass.

## Before replacing an older installation

Keep copies of important projects. Legacy ZIP projects open as separate native documents; save under a new name. Choreography is reauthored and may differ from older exports. Older apps cannot read the new native package format.

**Movies are silent:** source audio, soundtrack playback/export and WebM are not included. HDR mastering and low-memory real-time performance across all scenes are not certified. Broader hardware, accessibility and long-session testing remains necessary.

## Installation

Download **Galileo.Gallery-2.0.0-macOS-arm64.dmg**, open it and drag Galileo Gallery to Applications. Quit the old version first and choose Replace when Finder asks. Eject the disk image and launch from Applications.

The app is ad-hoc signed, **not Developer ID signed or notarized**. Apple's per-app Privacy & Security → Open Anyway path may be needed. Do not disable Gatekeeper globally or bypass a damaged/malware warning. See INSTALL.md.

The release supplies matching ZIP/DMG files, SHA256SUMS.txt and synthetic validation evidence. The source SHA in the bundle and validation record identifies what was actually built; successful automated checks are not a claim that every possible bug is fixed.
