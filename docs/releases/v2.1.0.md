# Galileo Gallery 2.1.0

Native Mac update for **Apple silicon and macOS 14 or later**. Sound is removed from the product roadmap and active workflow: movies are silent by design, while imported originals remain intact.

## Workflows completed

- Missing/damaged-media recovery copies, fingerprint-based Locate, Replace and explicit export blocking for unresolved included artwork.
- One import/save media budget. Replacement retains framing, spotlight, source rate and compatible trims, with a notice for a shorter clip.
- Spotlight preview, cue navigation/marks, adjustable entry/return duration and a finite closing hold.
- Visual crop handles, aspect lock, fill-position editing, Fit/100% zoom and panning; mixed-selection states and stable edit targets.
- Wrapped captions, optional contrast backing and a single caption for an assembled source.
- Selected PDF-page intake with original-PDF preservation, favourite scenes and a local preset library.
- Whole-sequence, selected-spotlight and custom-range export, plus a small serial queue.

## Corrected

Orbit routes with more than twelve sources no longer change visible slot identity at each item boundary. Orrery excludes its centre source from the satellites. Vitrine completes the outgoing image's departure. Paged tables and suspended galleries retain both sides of their handoff. Build assembles the complete slide for a spotlight and retains outgoing fragments during a multi-image exchange. Wipe/slice selection follows the visible part, not a hidden full rectangle. Narrow-window transport readouts no longer wrap timecode.

## Performance work

Preparation scales early to preview resolution. Immutable image resources and the CIContext are shared, worker video generators are bounded and memory pressure clears image caches. Preview does not cancel every playback tick. Movie composition writes directly into encoder buffers. Saves prefer independent APFS clones and reuse verified hashes only while fresh file identity matches.

These changes remove specific unnecessary work. Validation records its actual hosted Mac and measurement sample; real-time performance on every project and device is not promised.

## Upgrade and install

Quit the old app, keep copies of important projects, open **Galileo.Gallery-2.1.0-macOS-arm64.dmg**, and drag Galileo Gallery to Applications. Choose Replace, eject the DMG, then launch from Applications. See [INSTALL.md](../../INSTALL.md).

2.0 native documents open through in-memory migration. A new save uses schema 5, which 2.0 cannot read. Legacy ZIP projects open separately with conversion notes; keep the originals. Motion may differ from older exports.

The app is ad-hoc signed, **not notarized**. Use Apple's per-app Open Anyway process only for a trusted developer-verification warning, not a damaged/malware warning. Do not disable Gatekeeper globally.

Silent output is intentional. There is no WebM, HDR guarantee, cloud service or automatic updater. PDF pages are rasterized. Broader hardware, long-session and accessibility acceptance remain separate from the automated evidence attached to this release.
