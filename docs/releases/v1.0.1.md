# Galileo Gallery 1.0.1

This stable patch promotes the rebuilt one-to-one Galileo Scene catalogue after the repaired six-Atelier
handoff, exact-source integration, renderer evidence, and batched human review.

## What changed

- 29 original components now appear as 29 distinct catalogue Scenes instead of 17 grouped families.
- Every rebuilt Scene keeps its own identity, authored controls, evaluator/timing behavior, media
  treatment, accessibility semantics, and lifecycle cleanup.
- Quiet Carousel remains available as a compatibility Scene.
- Vitrine keeps its hardened v2 controls, portable Project round trip, fresh media grants, second-launch
  reopen, and corrupt/missing-media preservation behavior.
- Project exports retain the legacy schema boundary: new authored Scene parameters do not leak into
  exact-key legacy host exports.
- The macOS release artifact is packaged as a DMG and its mounted payload is launched before publication.

## Verification boundary

The release candidate must pass source tests on Ubuntu, macOS, and Windows; the G08 and G11 packaged
renderer journeys; native Linux AppImage, macOS Apple-silicon DMG, and Windows x64 portable builds; and
post-release artifact identity and launch smoke. Exact run IDs and SHA-256 values are recorded in the
external Phase 3 release receipt.

## macOS trust

The macOS build is ad-hoc signed for bundle integrity. It is not Apple Developer ID signed or notarized,
so Gatekeeper requires explicit user confirmation. The README contains the bounded installation steps.
