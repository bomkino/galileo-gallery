# Scene DNA — Spiral Image Vortex

## Silhouette-only still

Required marks:

1. one elongated, continuous helical thread spanning the stage longitudinally;
2. repeated left/right radial crossings around one implied axis;
3. obvious front and rear passages through scale/z-order, not opacity haze;
4. no centre pile-up, radial spokes, orbit ring, or scattered cloud;
5. endpoints absent because they live beyond the visible stage.

A still should look like frames threaded on a spatial screw. Remove colour, shadows, artwork, and any guide. The topology must survive.

## Five-second motion crop

A passing crop shows:

- stable source order sliding along one thread;
- at least one card moving from rear to near passage and another moving near to rear;
- z-order changing exactly at crossings;
- continuous tangent orientation;
- no source rotating randomly, duplicating, collapsing through centre, or popping through a fade;
- endpoint recycling only while fully offstage.

## Irreducible grammar

| Dimension | Vortex DNA |
| --- | --- |
| Topology | Open helix whose endpoints meet only through an offstage rear seam. |
| Path coordinate | One ordered scalar `u`; no independent particles. |
| Longitudinal motion | Monotonic pitch along canvas height. |
| Radial motion | Integer angular turns around the implied axis. |
| Depth | Sinusoidal front/rear passage with z-order crossings. |
| Orientation | Stable, path-derived, restrained camera-facing yaw. |
| Spotlight | Hold one source at the canonical near station. |
| Finale | Resolve the same thread around one selected near source. |
| Seam | Rear + offstage; no opacity window. |
| Material register | Threaded spatial procession, energetic but governed. |

## Anti-DNA

- flat Archimedean spiral;
- cards moving radially into/out of a centre;
- 2D screensaver;
- point cloud or random swarm;
- visible modulo duplicate;
- opacity seam;
- arbitrary per-card rotation;
- glow/streak/fog needed to communicate “vortex”;
- generic orbit with a vertical offset;
- camera spinning around static cards.

## Neighbour distinction

- **Calm Ring / Proximity Orbit:** closed ring circulation; Vortex advances along a longitudinal open helix.
- **Zoetrope:** one shallow cylinder and fixed front gate; Vortex has multiple spatial crossings and no percussive gate cadence.
- **Deck River:** depth corridor approaches/passes/recedes; Vortex winds around an axis while advancing longitudinally.
- **Scatter:** independent object positions; Vortex has one ordered thread.
- **Quiet Carousel:** linear focus well; Vortex has alternating front/rear crossings.

## Default signature

`8 items / 3 turns / radial spread 0.34 / depth pitch 0.28 / card size 0.22 / forward`

Controls may vary without losing the one-thread topology, offstage rear seam, ordered traversal, or near/rear crossing grammar.
