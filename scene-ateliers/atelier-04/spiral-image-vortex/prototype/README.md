# Spiral Image Vortex prototype

Self-contained clean-room laboratory. It uses one pure helix evaluator, generated local fixture media, and no Product imports, network media, dependency changes, or wall-clock evaluator state.

```sh
node verify.mjs
python capture.py
```

Open `index.html` through a local module-capable static server for interaction. requestAnimationFrame is transport-only; scrub/fixed samples call the same evaluator.
