# The Shelf deterministic prototype

Self-contained clean-room HTML/CSS/JavaScript laboratory. It proves natural-ratio widths, one stable baseline, deterministic source-identity lean, whole-row motion, offstage copy recycling, exact loop/reverse, causal Spotlight hold/straighten/lift, one/two/127-source behavior, horizontal portrait recomposition, failed/video identity, bounded observation, and alpha-safe minimal baseline output.

It is not Product code, a shared family engine, encoded export evidence, or human acceptance.

## Run

Open or serve `index.html`. No network or package install is required.

## Verify

```text
node verify.mjs
```

The receipt includes every seam record for the 127-source fixture.

## Capture

```text
python capture.py
```

Capture uses existing system Chromium and generated local SVG fixtures. It writes only to `../evidence/`.

## Important limits

- source-video timing is evaluator data; no real decoder opens;
- wall/ledge material is a laboratory visual context, not G10D Look implementation;
- generated fixtures do not prove external source RGB equality;
- horizontal-only is deliberate;
- no Product imports, dependencies, network media, registry changes, or shared Scene engine exist.
