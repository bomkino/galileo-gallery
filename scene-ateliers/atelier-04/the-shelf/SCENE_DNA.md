# Scene DNA — The Shelf

## Silhouette-only fingerprint

A horizontal row of differently wide rectangles shares one bottom baseline. Small stable tilts pivot from that line. No card floats. No single card sits in a permanent centre well. A one-item still remains visibly grounded by the baseline.

Reject the still if:

- all cards have one forced ratio;
- bottoms do not align;
- cards float above a decorative line;
- lean changes randomly or becomes theatrical;
- one card is permanently enlarged/centred;
- the ledge material, not the source row, carries identity;
- the composition could be rotated vertically without conceptual loss.

## Five-second motion fingerprint

- all editions translate with one track phase;
- spacing and source order remain stable;
- lean remains tied to identity;
- cards recycle only offstage;
- no same source appears twice;
- no neighbour dimming or centre magnet occurs;
- an authored Spotlight causes the track to ease, hold, then one print straightens/lifts while the rest stay grounded.

Remove colour, texture, shadows, labels, and wall. The crop must still read as walking past collected editions.

## Material register

Printed matter resting against a ledge. Slight placement differences matter, but the row is not messy. Physical contact and measured movement replace UI-carousel polish.

## Non-negotiable invariants

1. One shared baseline.
2. Natural-ratio widths.
3. Deterministic source-identity lean.
4. Whole-row translation.
5. Every recycling seam offstage.
6. No visible duplicate Project media.
7. Spotlight straightens/lifts and causally holds the track.
8. Horizontal-only identity.
9. Source opacity `1`, filter `none`, normal blend.

## Adjacent-Scene separation

| Adjacent Scene | Shelf distinction |
| --- | --- |
| Quiet Carousel | No centre bump/focus well; natural widths, baseline contact, lean, offstage seam machinery. |
| Filmstrip/Ribbon | Independent prints rest on a ledge; not one continuous strip. |
| Contact Table | One horizontal collected row, not a scanning grid/surface. |
| Scatter | Stable baseline and track, no table drift/collisions. |
| Vitrine | Many works remain a collection; no one-object negative-space hold. |
| Coverflow | No persistent depth fan or centred front plane. |

## Failure verdict

If the baseline can be removed without changing the Scene, or if the result reads as Quiet Carousel plus decoration, redesign or consolidate. Do not preserve it as a parameter preset.
