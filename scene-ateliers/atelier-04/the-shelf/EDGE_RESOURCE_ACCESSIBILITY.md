# The Shelf — edge, resource, and accessibility policy

## Edge cases

- **0 items:** explicit empty collection state.
- **1 item:** still edition on baseline; optional discrete Spotlight only.
- **2 items:** measured spacing with no forced duplicate or collision.
- **Recommended:** 5–24 media.
- **Bounded many:** 127 identities. Evaluator retains all; DOM mounts visible window plus overscan.
- **Mixed ratios:** common height, natural ratio-derived width, bounded extreme ratios.
- **Failed media:** stable placeholder width, caption, Spotlight eligibility, and order.

## Resources

Windowing keys by media ID and cumulative path interval. Offscreen videos pause or release decode pressure under Product policy. Captions outside the mounted visual window remain represented through accessible current or selected identity, not hundreds of focusable moving elements. ResizeObserver, animation frame, media listeners, and keyboard listeners are removed on disposal. No layout reads occur inside the pure evaluator.

## Accessibility

The moving stage is not a focus carousel. Scene selection, playback, scrub, and parameter editing remain in stable controls. Spotlight identity and caption are announced outside the stage. Reduced motion shows stable shelf tableaux and discrete focus. Keyboard users can select the same media identity without chasing moving cards. Visible focus, 44 px targets, readable labels, and non-colour state cues are required.

## Fallback

Without CSS 3D, render an ordered natural-width horizontal strip sampled from the same path, with discrete Spotlight selection. Fallback preserves baseline, order, natural widths, and captions; it does not become Coverflow.
