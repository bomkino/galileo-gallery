# Atelier 04 gauntlet protocol

Updated: 28 August 2026

The verifier is adversarial. It does not infer quality from file presence alone.

## Loops

1. **Identity:** compare each motion sentence and anti-goals against adjacent Scenes. Reject family-engine constants.
2. **Continuity:** sample starts, ends, phase boundaries, epsilon neighbours, reverse, reduced motion, and loop seam.
3. **Source:** inspect alpha-zero RGB, opacity, filters, blend, fit, failed-media identity, and transparent compositing.
4. **Interaction:** prove every control and gesture has one owner, one observable, a bounded reset, and one commit.
5. **Lifecycle:** remount, resize, context loss/restoration, animation cancellation, observer/listener cleanup, and GPU deletion.
6. **Review UX:** keyboard, touch targets, responsive layout, focus, reduced motion, forced colours, and honest verdict labels.
7. **Claims:** automated checks prove mechanics only. Human taste remains pending. Orrery remains blocked by G10A.

The Vortex and Orrery probes additionally test deterministic evaluator output, input immutability, finite instance matrices, invisible offstage recycling, identity-preserving Orrery exchanges, shader source-RGB identity, DPR bounds, instancing, context guards, and explicit disposal.
