# Vitrine deterministic prototype

Self-contained clean-room HTML/CSS/JavaScript laboratory. It proves one-object still holds, pair-bounded source-faithful exchange, exact reverse, finite entry/exit inversion, natural-ratio canvas recomposition, failed/video identity, 127-source observation bounds, optional external placard, reduced motion, and clean transparency.

It is not Product code, export integration, package evidence, or human acceptance.

## Run

Open or serve `index.html`. No network or package install is required.

## Verify

```text
node verify.mjs
```

## Capture

```text
python capture.py
```

Capture uses existing system Chromium, generated local SVG fixtures, and writes only to `../evidence/`.

## Important limits

- source-video visual timing is evaluator data; no real decoder is opened;
- generated fixture fidelity is not external-source RGB equality;
- opaque viewing-room field is laboratory presentation, not G10D Look implementation;
- reflection, sheen, and source lighting are intentionally absent.
