# The Orrery laboratory prototype

Status: **G10B preflight candidate; implementation blocked by G10A**

Self-contained clean-room DOM/CSS 3D laboratory. It proves deterministic primary authority, nested ring membership, signed integer revolution reconciliation, front/behind ordering, continuous directed primary exchange, control causality, 127-source observation bounds, reduced motion, and alpha-safe transparent output.

It is not Product code, a renderer decision, an active G10B ticket, or human acceptance.

## Run

Serve or open `index.html` in a modern browser. No network media or package install is required.

## Deterministic verification

```text
node verify.mjs
```

## Evidence capture

```text
python capture.py
```

Capture uses existing system Chromium and generated fixtures. It writes only inside `../evidence/`.

## Controls

- ring count Auto/2/3;
- orbit size;
- vertical squash;
- satellite scale;
- orbit pace;
- separate serialized-intent laboratory fields for primary, exchange target, exchange enable, and Timeline direction.

## Fixture caveat

All images are generated local SVG fixtures. A failed-media slot and source-video timing record are mechanical evidence only. No external user media, audio, Product save/open, export, packaging, or target-platform performance is tested.
