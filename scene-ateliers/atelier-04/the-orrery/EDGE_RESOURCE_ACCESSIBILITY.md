# The Orrery — edge, resource, and accessibility policy

## Gate

**G10B preflight candidate; implementation blocked by G10A.** These limits are study constraints, not Product capability claims.

## Edge cases

- **0 items:** explicit empty state; no decorative planets.
- **1 item:** one genuinely still primary. No phantom satellites.
- **2 items:** primary plus one satellite; exchange uses reciprocal continuous paths.
- **Recommended:** 9–21 media over three rings.
- **Bounded many:** 72 identities. DOM renders a stable visible/near window; WebGL uses one bounded instance set.
- **Mixed ratios:** source orientation remains intact inside independent frame planes.
- **Failed media:** stable ID, ring membership, exchange order, and readable placeholder.

## DOM resources

Stable keys follow media IDs, not ring slots. Expensive geometry derives from pure evaluator output and does not trigger layout reads per frame. Observers, animation frames, media listeners, and keyboard listeners are removed on remount/disposal.

## WebGL comparison resources

One generated atlas texture, one quad buffer, one instance buffer, one vertex array, one program, and one fixed authored camera. DPR is capped at 2. Paused state renders on demand only. Context loss stops playback and preserves durable evaluator state; restoration recreates all GPU resources. Disposal deletes texture, buffers, vertex array, program, observer, listeners, and animation frame. WebGL absence returns to the canonical DOM study.

## Accessibility

No generic orbit camera. Playback and scrub belong to Timeline/review transport. Parameter editing belongs to Inspector. Reduced motion uses stable system tableaux and announced identity changes. Focus does not chase moving bodies. Current primary identity and blocked gate status are exposed outside the stage. Controls require visible focus, readable labels, 44 px targets, and non-colour state cues.

## Fallback

Fallback preserves one primary plus an ordered satellite diagram sampled from the same evaluator. It cannot silently flatten into a different carousel identity.
