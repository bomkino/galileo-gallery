# The Orrery — Scene DNA

## Identity

A hierarchical orbital system with one stable primary and authored identity exchange. It is not defined by circular movement alone.

## Spatial grammar

- one optical centre;
- three distinct nested orbital planes;
- stable ring membership per media identity;
- integer-period signed ring motion;
- primary plane remains camera-readable;
- fixed authored camera;
- generous negative space between primary and satellites.

## Temporal grammar

`stable primary + orbital drift → incoming approach → identity-preserving centre exchange → outgoing ring rejoin → settle → repeat through all identities → exact system seam`

Every exchange is a continuous handoff, not a crossfade. The incoming media object becomes primary; no substitute object impersonates it.

## Distinction

- Unlike Orbit: multiple ring planes and primary inheritance are essential.
- Unlike Vortex: bodies stay on rings; no shared helix or offstage wrap.
- Unlike Zoetrope: no viewing gate or ratchet.
- Unlike Coverflow: no linear browsing plane.

## Default taste

18 bodies; three rings; signed speeds +1/−2/+3 turns per full loop; measured centre exchange; restrained depth; contain fit; no celestial Look effects.

## Deletion test

Remove primary inheritance and it becomes a decorative orbit. Remove independent rings and it becomes Orbit Ring. Remove integer-period closure and the system visibly tears at the seam. All three are essential.
