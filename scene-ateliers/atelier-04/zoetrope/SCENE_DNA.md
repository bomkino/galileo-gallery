# Scene DNA — Zoetrope

## Recognition test

### Silhouette-only still

A passing still contains four non-negotiable marks:

1. one upright rectangle square to camera at a narrow central front gate;
2. several upright rectangles turning progressively edge-on to either side;
3. a shallow cylindrical horizon rather than a broad flat ellipse;
4. a compressed or absent rear band, produced by occlusion rather than fog.

Remove colour, texture, captions, shadow, and imported imagery. If the composition can be mistaken for Calm Ring, Wide Ellipse, Coverflow, or a horizontal carousel, fail it.

### Five-second motion crop

A passing crop shows at least four complete slot advances. Each advance has:

- a decisive, eased travel;
- a brief but visible gate dwell;
- stable tangency through the sides;
- no angular backtracking;
- no source pop, random flicker, blur wash, or reordering;
- exact source identity arriving at the next gate.

The crop should sound mechanical even when muted: travel, settle, travel, settle. Continuous floating is wrong.

## Irreducible grammar

| Dimension | Zoetrope DNA |
| --- | --- |
| Topology | One shallow cylinder around a vertical axis. |
| Hierarchy | Gate frame readable; side frames transitional; rear frames occluded. |
| Orientation | Upright source planes tangent to cylinder; front plane square to camera. |
| Time | Slot-quantized authored cadence with continuous eased travel and explicit dwell. |
| Order | Stable source order around one ring. |
| Depth | Geometric projection and occlusion, never source dimming. |
| Spotlight | Timeline-selected source held at fixed front gate. |
| Finale | One final gate-aligned settle, not a generic zoom. |
| Seam | One complete source cycle returns every identity and pose exactly. |
| Material register | Optical/mechanical apparatus, brisk and disciplined. |

## Anti-DNA

- calm orbiting;
- a broad ellipse with always-readable cards;
- continuous speed with no gate cadence;
- a stack, deck, ribbon, or point cloud;
- opacity-driven rear falloff;
- pointer-thrown momentum as story state;
- wall-clock idle movement;
- random tilt or per-card phase;
- motion blur used to conceal sampling failure;
- duplicate source identities used as loop machinery.

## Distinction from neighbours

- **Quiet Carousel:** Quiet Carousel travels through a linear focus well. Zoetrope rotates tangent planes through a fixed cylindrical gate.
- **Calm Ring:** Calm Ring is continuous spatial circulation. Zoetrope is percussive apparatus cadence.
- **Proximity Orbit:** Proximity Orbit derives emphasis from nearness and scale. Zoetrope derives readability from a fixed gate and tangency.
- **Wide Ellipse:** Wide Ellipse preserves a broad spatial panorama. Zoetrope is shallow, compressed, and machine-like.
- **Filmstrip/Ribbon:** Ribbon translates planar media along a material strip. Zoetrope rotates discrete planes around an axis.

## Default signature

`6 items / radius 0.39 / card size 0.31 / tilt −4° / ratchet / forward`

This signature is a candidate, not a hidden dependency. Every control can move within its declared range without erasing the cylinder, gate, tangency, or authored cadence.
