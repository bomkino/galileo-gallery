# Atelier 04 gauntlet

Run from the repository root:

```bash
node scene-ateliers/atelier-04/gauntlet/verify.mjs
node scene-ateliers/atelier-04/gauntlet/adversarial.mjs
node scene-ateliers/atelier-04/gauntlet/fuzz.mjs
```

## What each layer owns

- `verify.mjs` — packet completeness, deterministic evaluators, epsilon continuity, offstage recycling, identity handoffs, source/alpha contracts, review UX, WebGL lifecycle, offline behaviour, and claim discipline.
- `adversarial.mjs` — metamorphic control causality, legal extremes, renderer parity seams, interaction ownership, and deliberate non-WebGL decisions.
- `fuzz.mjs` — 2,500 seeded legal parameter cases across counts, ratios, directions, canvas dimensions, control ranges, exchange boundaries, matrices, and recycling.

These scripts prove mechanics only. They do not approve visual taste, source-pixel equality against real user media, Product integration, packaging, release, or human acceptance. The Orrery remains a **G10B preflight candidate; implementation blocked by G10A**.
