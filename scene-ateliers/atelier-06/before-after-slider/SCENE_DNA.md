# Scene DNA — Before / After

## Identity lock

**Object:** one comparison plane.

**Primary verb:** reveal.

**Secondary verb:** verify.

**Never:** dissolve, enhance, register, grade, or fabricate.

## Geometry

Before and After occupy the same stable rectangle. After is the base layer; Before is clipped by a single straight divider. The divider may be vertical or horizontal. It does not bend, ripple, glow across artwork, or create a lens effect. Labels live in their own backed UI regions.

The frame is centred with generous negative space. Ratio mismatch remains visible under contain. The Scene does not infer a common crop. Failed media preserve the relevant side and display a causal placeholder.

## Count grammar

- 0 items: empty guidance.
- 1 item: insufficient comparison input; no duplicate.
- 2 items: valid Scene.
- 3+ items: first two only if their semantic roles are explicit; otherwise invalid. Extras are reported and preserved outside evaluation.

## Temporal grammar

A canonical phrase begins at 0%, travels to 100%, holds, returns to 0%, and holds. Each travel uses a smooth monotonic curve. Endpoint holds have zero velocity. The end state equals the start state exactly.

Directed compilation repeats complete comparison phrases at actual pace scales 2, 2, 1, and 2. A mode badge without changed duration or evaluator output is invalid.

## Differentiation

This Scene is not a carousel, crossfade, wipe transition, or image editor. Its identity survives only if two stable roles, one shared plane, one legible divider, and continuous reversible travel remain intact.

## Default recommendation

Vertical divider, Before left / After right, contain fit, 1200 ms travel, 650 ms endpoint hold, 2 px high-contrast divider, backed labels, opaque output.
