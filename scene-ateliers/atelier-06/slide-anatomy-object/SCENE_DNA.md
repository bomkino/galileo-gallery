# Scene DNA — Slide Anatomy

## Identity lock

**Object:** truthful presentation cutaway.

**Primary verb:** explain.

**Secondary verb:** separate.

**Never:** fabricate, segment, decorate, or dramatise authorship.

## Plane grammar

The candidate owns at most these stable planes:

1. world backing;
2. frame surround or matte;
3. indivisible source plane;
4. optional guide apparatus already present in Project intent;
5. optional caption apparatus already present in Project intent.

Absent planes do not exist in the evaluator, DOM, timeline, or evidence. Their phases and labels disappear rather than becoming invisible placeholders.

## Geometry

All planes share one source-aligned coordinate system. Separation uses shallow z and modest x/y offsets derived from canvas ratio. The source plane stays front-facing enough to remain legible. Planes never cross; return is the exact inverse of opening. Labels sit outside the planes with leader lines that never touch source pixels.

## Count grammar

This Scene evaluates one source identity. Zero sources is an empty guidance state. More than one source remains preserved by the Project but requires explicit selection before evaluation. It does not create a sequence or stack of unrelated slides.

## Temporal grammar

Entry establishes the closed source. Opening separates present planes. Open hold permits reading. Closing retraces all positions and opacity states. The end equals the start exactly. Empty caption, absent guides, and absent matte reduce both plane count and duration.

Directed mode changes actual segment durations and repeats full phrases at pace scales 2, 2, 1, and 2. It does not apply the casino label to one unchanged cosine.

## Differentiation

- **The Build:** narrates an authored sequence of known construction stages if such stages exist.
- **Slide Anatomy:** explains the stable present structure of one Project-owned presentation object, then returns.

If semantic layers are inferred from source pixels, this Scene fails its identity even if the animation looks impressive.

## Default recommendation

Flat-source mode; source + matte + guides + caption only when present; 14% maximum depth separation; 7° viewing angle; 900 ms open, 1400 ms hold, 900 ms close; contain fit; clean transparent-capable world; labels on for review, off for export unless authored.
