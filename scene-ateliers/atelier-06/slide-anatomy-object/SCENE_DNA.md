# Scene DNA — Slide Anatomy

## Identity kernel

Analytical separation, readable inspection, exact return.

## Silhouette

- one intact source rectangle remains recognisable;
- a shallow exploded stack of frame/mat/guide planes;
- short leader labels owned by Project-known structure;
- no incremental assembly, cursor, palette, stamp, particles, or process trail.

## Source contract

The source is one flat media item. The Scene can analyse presentation apparatus only. Multiple arbitrary media items are not semantic layers.

## Topology

| Plane | Project-known basis | Can overlap source pixels? |
| --- | --- | --- |
| backing/mat | frame presentation | behind only |
| source frame | media item | source itself |
| frame edge | frame presentation | edge only |
| safe-area guide | Project canvas safe padding | guide stroke only; prototype/debug semantics |
| caption strip | media caption field | outside source rectangle |

No plane is named “typography,” “texture,” “annotation,” “brand,” or “polish.”

## Temporal grammar

- separation and return are one path with opposite parameter direction;
- full inspection is a real hold;
- source never assembles additively;
- finale resolves the exact original source frame;
- reverse is mechanically exact;
- reduced motion selects discrete endpoints.

## Distinction from The Build

| Axis | Slide Anatomy | The Build |
| --- | --- | --- |
| Question | What Project-known apparatus surrounds this source? | How does presentation apparatus accumulate into a resolved frame? |
| Direction | separate, inspect, exact return | additive beats, cleanup, resolve |
| Hold meaning | inspect simultaneous planes | read one authored construction decision |
| Source contract | one flat source | one flat source apparatus fallback; explicit stages only after schema |
| Finale | untouched source restored after reverse | finished source held after additive sequence |

If this Scene tells a sequence of design decisions, it has become The Build and failed.

## Anti-patterns

- inferred semantic layers;
- historical generic tags on user art;
- slicing source pixels into pseudo-layers;
- perspective spectacle;
- non-identical return path;
- source filter/opacity changes;
- using arbitrary extra media as layers;
- shared phase engine.

## Deletion test

Delete the directory and no Product or neighbouring prototype changes. No shared layer/phase framework is introduced.
