# Scene DNA — The Build

## Identity lock

**Object:** authored construction sequence.

**Primary verb:** build.

**Secondary verb:** reveal intent.

**Never:** fabricate process, simulate software, or decorate a flat image with arbitrary fragments.

## Two capability states

### `flat-source-preflight` — available here

One intact source plane plus Project-known presentation apparatus. Purpose: test pacing, spatial lanes, stage legibility, finale, controls, and contract pressure without pretending to know historical design stages.

### `authored-stages` — blocked

Requires a versioned Project contract. Every stage needs stable ID, label, order, source/provenance, bounds, transform, alpha, timing intent, optional dependency, and final-state relationship. The Scene cannot infer these from pixels.

## Stage grammar

A valid stage must change declared output and contribute to the final composition or its explanation. It cannot exist only to make the animation longer. Present preflight stages:

1. establish world;
2. establish safe frame/matte when Project-owned;
3. establish guide/caption apparatus when Project-owned;
4. present intact source;
5. finale hold.

Absent apparatus deletes its stage and contracts duration. No invisible wait remains.

## Geometry

Stages occupy deterministic lanes around a stable hero source. Incoming paths are non-crossing and return paths are exact inverses. Stage z-order is explicit. The finale restores full source readability with no lingering UI above artwork. Labels live outside the hero plane.

## Temporal grammar

The default 11.6 s phrase gives each present stage an arrival, settle, and read allowance, followed by a substantial finale hold. The dynamic floor is 7.9 s for the canonical preflight set and recomputes from present stages. Durations below the floor fail.

Directed compilation changes actual phrase speed at scales 2, 2, 1, and 2. The regular phrase carries the full reading allowance. Reverse is an inverse presentation, not a different stage order claim.

## Differentiation

- **Slide Anatomy:** explains stable present structure, opens and returns.
- **The Build:** narrates an explicit ordered progression toward a final state, but only with truthful authored stages.

Without a future authored-stage contract, The Build must remain visibly labelled preflight. Removing that label would turn a useful study into false process theatre.

## Default recommendation

Flat-source preflight, canonical five-stage ledger, 11.6 s duration, 2.6 s finale hold, contain fit, 0.96–1.0 presentation scale, source-clean world, labels on in review, no fake cursor/stamp/palette/wireframe.
