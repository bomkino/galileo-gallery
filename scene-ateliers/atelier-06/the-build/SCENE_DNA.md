# Scene DNA — The Build

## Identity core

**Additive authored presentation beats that clear into one exact finished source.**

The Build is not a generic explainer. It does not explain the artwork. It explains only Gallery's visible, Project-known act of presenting the artwork.

## Silhouette

1. Empty stage anchor.
2. Neutral frame arrives.
3. Guide geometry appears.
4. One source window fills.
5. Temporary apparatus clears.
6. One resolved frame holds.
7. Apparatus honestly deconstructs.

The silhouette remains recognisable without texture, colour, copy, or decorative effects.

## Spatial grammar

- Stable frontal camera.
- One source window centred inside a neutral frame.
- Guides align to canvas/frame geometry, never to inferred artwork features.
- Optional caption sits in a declared Project-caption zone.
- Cursor, when enabled, traces only one actual placement path and disappears before the final hold.

## Temporal grammar

The narrative direction is additive: apparatus → placement → cleanup → resolved source. Deconstruction exists only to close the loop honestly. Holds certify decisions; they are not pauses inserted for duration.

## Five identity invariants

1. Source remains one intact plane.
2. Every beat has a named Project-known purpose.
3. Temporary scaffolding disappears before finale.
4. Finale is source-faithful and visually quiet.
5. No phase exists solely to decorate or imply hidden authorship.

## Forbidden moves

- inferred type/image/palette/texture/brand layers;
- fake `approved`, `ready`, or completion stamps;
- generic cursor choreography unrelated to a Project-known operation;
- particle, bloom, ray, ripple, warp, confetti, caustic, or lighting flourish;
- universal explanatory or phase engine;
- using extra media as stages without explicit authored roles;
- compressing readable middle decisions to preserve a nominal duration.

## Distinction from Slide Anatomy

| Axis | Slide Anatomy | The Build |
| --- | --- | --- |
| Source contract | one flat source plus analytical presentation planes | one flat source plus additive presentation apparatus |
| Topology | planes separate away from an intact source | apparatus accumulates around an intact source |
| Temporal direction | resolved → separated → exact return | empty → constructed → resolved → honest deconstruction |
| Hold meaning | inspection | decision readability |
| Finale | original resolved source after return | finished presentation after temporary apparatus clears |
| Core verb | inspect | construct |

If these differences disappear in silhouette or real-speed playback, consolidate rather than vary overlay counts.

## Deletion test

The prototype imports no other Scene prototype, no shared editorial evaluator, and no universal phase engine. Deleting `the-build/prototype/**` changes no Product source or other atelier. Production may propose a shared primitive only after two approved Scene implementations and a deletion/depth test.
