# The Build disposable prototype

Self-contained G10C preflight study. It is not a Product Scene, shared phase engine, Project schema, or formal charter approval.

Run:

```sh
node check.cjs
CHROMIUM_BIN=chromium python capture.py --output ../evidence
python verify_evidence.py ../evidence
```

Open `index.html` directly for play, pause, scrub, automatic/fixed/directed compilation, reset, canvas ratios, reduced motion, source-count fixtures, and debug geometry. The same pure evaluator drives playback, scrub, and fixed-step capture.

Generated fixtures only. No network media. Deleting this directory has no Product effect.
