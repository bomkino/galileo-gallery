# Scene DNA — Light Table

## Identity kernel

A deterministic illuminated working surface. Sources are already present. The Scene does not celebrate their arrival; it helps a human inspect them.

## Silhouette

- broad opaque table plane;
- loose but controlled overlapping rectangles;
- one slightly raised inspection frame;
- under-light visible only as a halo outside frame bounds;
- no conveyor, orbit, fan hinge, or indexed Contact Sheet grid.

The silhouette must survive monochrome rendering. Removing colour leaves a recognisable table, overlaps, inspection bay, and focus outline.

## Spatial grammar

| Axis | Rule |
| --- | --- |
| Topology | stable source-index slots; explicit 1/2/5/6 policies; ratio-aware bounded review grid for 7–24 |
| Depth | three bands: table, resting frames, inspected frame |
| Occlusion | permitted only within declared overlap budget; source identity never hidden completely |
| Camera | fixed orthographic review view; no perspective flight |
| Negative space | one deliberate inspection bay at five; perimeter breathing room at all ratios |
| Recomposition | landscape spreads horizontally; portrait compresses into vertical bands; square and 4:5 balance around centre |

## Temporal grammar

- movement is secondary to inspection;
- transit is shorter than hold;
- drift amplitude stays below visible handling gesture;
- all drift is periodic and seam-safe;
- focus follows Project order;
- final inspection resolves to neutral table without teleportation.

## Source grammar

Source pixels are evidence, not raw material for lighting. Media remains one opaque/alpha-preserving internal canvas at opacity 1 with no filter. The table can glow around the frame; it cannot make the image glow.

## Anti-patterns

- indexed/repeated contact-sheet cells;
- continuous arrival-field motion;
- random re-layout on remount;
- draggable physics not serialized to Project;
- card brightness/dimming to indicate focus;
- tint, blend, glow, or grain over art;
- fake piles when count is one or two;
- one source duplicated to fill topology.

## Neighbour distinction

### Versus Contact Sheet

Contact Sheet earns identity through systematic grid scanning. Light Table earns identity through controlled overlap, opaque illumination, and inspected handling. At high counts the bounded topology may use rows, but if repeated cells, indexing, or regular scan order become the dominant identity, this Scene has failed.

### Versus Lively Prints

Lively Prints earns identity through arrival-field energy and lively mosaic motion. Light Table begins settled and remains review-still. If motion becomes the subject, this Scene has failed.

### Versus Vitrine

Vitrine isolates one precious object. Light Table keeps a working set visible and one item temporarily inspectable. The loupe must never erase the surrounding table context.

## Deletion test

Deleting this prototype removes no shared engine and changes no other Scene packet. Its topology, evaluator, controls, fixtures, and renderer are local. A future shared primitive is not proposed from this single use.
