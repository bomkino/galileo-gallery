# Scene DNA — Light Table

## Identity lock

**Object:** illuminated editorial work surface.

**Primary verb:** inspect.

**Secondary verb:** scan.

**Never:** fling, shuffle, orbit, fan, stack, or auto-crop.

## Geometry

A bounded matrix lives inside a stable table aperture. Layout is deterministic from canvas width, canvas height, item count, density, and source ratios. Rows and columns are selected to minimise unused area without allowing overlap. Each media identity owns one cell for the full phrase.

The active frame gains modest scale and z-order. Neighbours retain enough room to remain legible. The loupe is not a translucent colour wash; it is a world-space surround and small physical lift.

## Count grammar

| Count | Grammar |
| ---: | --- |
| 0 | Empty-stage guidance; no fabricated frames |
| 1 | Centred inspection plate with a quiet breathing hold |
| 2 | Equal comparison pair |
| 3–6 | Normal review matrix |
| 7–12 | Dense matrix; captions only for active item |
| 13–24 | Bounded overview; smaller cells, active item remains readable |
| >24 | Windowed Product policy required; prototype clamps visibly and reports the consequence |

## Ratio grammar

Cell geometry honours each source ratio. Clean uses contain. Transparent sources may remain transparent if the shared Look supports it; table light may not leak RGB into alpha-zero pixels. Portrait canvases favour fewer columns. Square and 4:5 canvases retain the same order and inspection path.

## Temporal grammar

One review step contains travel, settle, hold, and release. Travel uses a monotonic easing curve. The frame does not overshoot or teleport. A full pass visits each identity exactly once before the seam.

Directed compilation uses four cycle phrases: fast, fast, regular, fast. It changes actual segment duration and velocity rather than attaching labels to an unchanged curve.

## Differentiation

- **Contact Sheet:** overview-led, many-at-once survey.
- **Deck Contact Strip:** linear scanning strip.
- **Light Table:** settled matrix with one explicit inspection focus and tactile review-room calm.

Deleting the loupe path, stable cells, and count-specific composition would destroy Light Table identity. It cannot be reduced to constants in a generic grid renderer.

## Default recommendation

Six items, three columns on 16:9, two columns on 9:16, contain fit, 1.08 active scale, 700 ms travel, 900 ms hold, warm neutral table world, no source treatment.
