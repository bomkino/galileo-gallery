# Edge, resource, and accessibility contract — Light Table

## Edge matrix

- **Zero items:** show empty-stage guidance; evaluator returns no media cells.
- **One item:** centred inspection plate; no fake grid or repeated copy.
- **Two items:** equal pair; both remain readable.
- **Six items:** canonical matrix.
- **Twenty-four items:** bounded dense matrix; collision test required.
- **More than twenty-four:** preserve Project order; expose an explicit windowing consequence. Never allocate unbounded hidden cells.
- **Mixed ratios:** source ratio controls media box; contain default.
- **Failed media:** stable placeholder with original identity and position.
- **Video:** deterministic story-time seek; native autoplay is not authority.
- **Transparent media:** source alpha preserved; table layers remain behind.

## Layout safety

Compiled cells must stay inside the table safe area and may not overlap at rest. The active scale may approach neighbours only within a declared 2 px visual tolerance and receives the highest z-order. Portrait canvases reduce columns before reducing minimum readable cell size.

## Browser lifecycle

The study owns at most one animation-frame callback, one resize observer, one keyboard listener, and one media-time synchroniser per mount. Disposal cancels animation, disconnects observers, removes listeners, pauses media, clears pending seeks, and revokes generated object URLs. Remount produces the same first frame and no duplicate event response.

## Interaction

- Space: play/pause.
- Arrow keys: scrub one review step; axis follows the visible review order rather than canvas orientation.
- Home: start.
- End: final settled item.
- Escape: clear keyboard focus from the stage only when the surrounding Product owns a safe destination.

Controls have visible focus, readable labels, and a minimum 44 × 44 px target. Playback state, mode, duration, and selected frame are exposed as text. A polite live region announces explicit user actions, not continuous animation.

## Reduced motion

No travelling loupe, pulsing light, or automatic focus cycling. The Scene presents a stable representative inspection state. Manual keyboard selection remains available with an immediate state change.

## Colour and contrast

World controls and labels target WCAG AA contrast. The Scene never adds a translucent label over artwork without its own opaque backing. Failed-media copy remains legible independent of Look.

## Fallback

If transforms, observers, media decode, or accelerated composition are unavailable, render the same ordered static matrix with contain fit and explicit failed-media placeholders. Do not drop the Scene or substitute a generic carousel.
