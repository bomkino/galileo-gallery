# Edge, resource, and accessibility policy — Light Table

## Edge matrix

| Condition | Candidate behaviour |
| --- | --- |
| 0 sources | apply fails before Project mutation |
| 1 source | one large inspected transparency; no pile fiction |
| 2 sources | bilateral table; stable left/right source identity |
| 5 sources | valid compact composition with a deliberate open bay |
| 6 sources | ordinary composition and recommended default |
| 7–24 sources | deterministic ratio-aware review topology with bounded overlap and ordered focus route |
| >24 sources | preserve all; report v1 visible limit; no silent drop |
| mixed ratios | independent frame ratios; topology recomposes around them |
| failed source | same slot/order/ID; neutral failed frame; no substitution |
| source video | frame follows Product story time; Scene adds no media clock |
| transparent request | unavailable with exact capability copy |
| tiny canvas | preserve source legibility; reduce overlap and nudge before frame size |
| remount/resize | recompute from IDs, count, controls, and stage; exact repeat |

## Keyboard and focus

- Stage is a labelled group.
- Exactly one source frame is in the page Tab order at a time; each frame is a button-like inspection target named from Project name/caption.
- Arrow Right/Down advances in Project order; Arrow Left/Up retreats.
- Home and End select first/last.
- Enter toggles the manual loupe; Escape clears it.
- The roving tab stop follows keyboard focus without creating 24 sequential Tab stops.
- Focus ring is outside source pixels and meets contrast on the opaque table.
- No hover-only information.

## Reduced motion

- stable arrangement remains;
- periodic nudge and automatic focus transit become zero;
- one authored focus is indicated by static outline and exterior under-light;
- no scale pulse;
- keyboard inspection remains available;
- source-video policy remains Product-owned.

## Resource budget

For `N <= 24`:

- one stage root;
- `N` frame roots;
- `N` source canvases;
- `N` under-light elements;
- one focus outline per active frame, not one global animation object per tick;
- no interval;
- one animation-frame callback only while playing in the prototype;
- production evaluator and layout storage O(N); the independent O(N²) rectangle-overlap oracle exists only in checks/evidence;
- zero network requests;
- no GPU context required.

## Lifecycle

`dispose()` cancels playback, disconnects the stage `ResizeObserver`, clears the ephemeral manual loupe and roving focus, and removes generated source nodes. `mount()` reconnects the observer and recreates state from controls, fixture identity, and story time. Dynamic frame listeners disappear with their removed nodes; the prototype's static control-shell listeners remain bound for the document lifetime. Remount evidence compares evaluator state and bounded DOM counts.

## Failure copy

- Zero source: `Light Table needs at least one source.`
- More than 24: `Light Table shows up to 24 sources in v1. All Project media remain preserved.`
- Transparent request: `Light Table needs an opaque illuminated surface. Transparent export is unavailable for this Scene. Choose another Scene to preserve alpha.`
