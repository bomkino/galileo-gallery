# Start six Galileo Scene Ateliers

These six branches are deliberately isolated research-and-design lanes. They let six strong model
contexts spend serious attention on every named Scene without six writers colliding in the Product
renderer, registry, schema, or shared contracts.

## Launch procedure

For each row below, open a new GPT-5.6 Sol Pro chat with the highest available reasoning effort:

1. Attach the same Drift + Galileo Gallery Cloud Work mega kit.
2. Connect `bomkino/galileo-gallery` through GitHub.
3. Select the exact pre-created branch in the row. Never use `main` or another atelier branch.
4. Paste the entire matching prompt file as the first instruction.
5. Let the chat inspect, write, review, test, commit, and push only its owned atelier directory.
6. Do not ask it to open a PR or integrate Product source.
7. When it finishes, return its branch name, final commit/tree, `ATELIER_RECEIPT.md`, evidence,
   and human-review packets to the serial Gallery integration thread.

## What comes back

Each atelier returns one complete packet per assigned Scene: candidate charter, distinctive Scene
DNA, causal control contract, deterministic Timeline/evaluator design, source/alpha/Look boundary,
edge/resource/accessibility contract, provenance record, canonical test vectors, disposable
prototype evidence, and a focused human-review packet whose verdict remains pending.

The main Gallery thread compares all packets, obtains the necessary human charter decisions, and
later promotes at most three disjoint S1 Scene implementations concurrently after the G10D shared
Look/Scene boundary freezes. One serial catalogue owner integrates shared registry and contract
changes. This preserves both parallel creative depth and coherent Product architecture.

## Stop and return instead of improvising

An atelier stops only for repository or branch mismatch, another writer on its exact branch, an
unsafe source conflict, or inability to preserve its write boundary. Missing historical references
are not a blocker: record provenance unavailable and continue with principle-level clean-room work.
