# Edge cases, resources, and accessibility — Quiet Drift

## Source-count policy

| Count | Behaviour |
| ---: | --- |
| 0 | Product should show capability copy; prototype rejects. No fake placeholder crowd in final Scene. |
| 1 | Centred, weighty print; optional minute breath; no traversal fiction. |
| 2 | Deliberate counterweight; stable left/right roles; no oscillating swap. |
| 3–7 | Primary intimate clustered composition. |
| 8–12 | Smaller bounded cluster retaining every ordered identity. |
| >12 | Explicit rejection in this candidate; never silent truncation or repeated slots. |

## Mixed and failed media

Landscape, portrait, square, cinematic, and vertical frames coexist. Width derives from declared source ratio while height follows the canvas-aware print scale. Product per-frame fit remains upstream.

A failed item keeps:

- original ID and source index;
- compiled neighbourhood;
- card dimensions and z role;
- focus traversal position;
- visible crossed placeholder.

Removing the slot would alter composition and make later IDs move, so it is forbidden.

## Canvas edges

The evidence packet covers 1920 × 1080, 1080 × 1920, 1080 × 1080, and 1080 × 1350. The compiler scales around centre and sizes from the shorter dimension. S1 must additionally enforce safe bounds after real font/caption apparatus is known. No source should clip merely because it is portrait.

## Reduced motion

Reduced motion freezes current fields and rotation. It keeps all media present and readable. Keyboard selection may show a static external registration outline; it does not animate lift. The arrangement is not replaced with a generic list or blank stage.

## Focus and keyboard order

DOM focus order must remain source order. Base z and focus-plane z are visual only. Arrow navigation wraps predictably across ordered sources; Home/End expose seam states in the prototype, while Product Home/End behaviour requires wider studio review. Focus is never moved by the animation clock.

A source should expose an accessible name assembled from source name/caption, one-based index, failed status, and selected/attention state. Decorative paper edges and debug geometry remain hidden from accessibility APIs.

## Resource bounds

- hard candidate maximum: 12 sources;
- evaluator states per frame: exactly accepted source count;
- duplicate loop copies: 0;
- retained prior frames: 0;
- evaluator timers/listeners: 0;
- network requests: 0;
- generated fixture media only;
- 2,000-frame observation: stable twelve-card output with no collection growth.

Browser preview owns one `requestAnimationFrame` transport callback. The evaluator does not own it. S1 must cancel the callback, release decoded media/proxies, disconnect resize observers, and release any texture/card resources on unmount or context loss.

## Fallback and context loss

A 2D/CSS fallback can preserve the complete identity: stable cluster, closed small translations, fixed z, focus outline. WebGL is not required. On GPU/context loss, fall back to static remembered places rather than hiding sources or restarting with a different seed.

## Performance claims not made

No heap profiler, long-running browser remount run, real decoded video stress test, GPU context-loss harness, or Product export benchmark ran here. The packet proves bounded pure-state mechanics only.
