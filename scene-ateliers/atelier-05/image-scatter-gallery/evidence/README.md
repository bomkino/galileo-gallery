# Lively Prints evidence

Generated from local synthetic fixtures only.

```sh
node prototype/verify.mjs
node prototype/capture.mjs
```

`stills/` holds canonical times and boundaries. `ratios/` holds exact 1920×1080, 1080×1920, 1080×1080, and 1080×1350 compositions. `fixtures/` covers one, two, recommended, bounded-many, and failed media. `motion/` is a 48-frame fixed-step sequence at 24 fps. `silhouette/` contains a still and 24-frame silhouette playback. `alpha/` contains five composites. Debug evidence exposes routes and exclusion geometry only. Diagnostics state all limitations. No browser recording or human verdict is claimed.
