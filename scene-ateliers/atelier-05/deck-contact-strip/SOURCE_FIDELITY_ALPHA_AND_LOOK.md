# Source fidelity, alpha, and Look — Focus Strip

## Clean source contract

Every valid source is represented with:

- artwork opacity: 1;
- filter: `none`;
- blend mode: `normal`;
- declared per-item contain/cover intent;
- declared ratio and focal intent retained as input;
- no selection-driven brightness, saturation, blur, tint, glow, vignette, or contrast change.

The station selects by registration geometry and restrained physical lift outside source pixels. Surrounding frames remain equally source-faithful.

## Documentary frame boundary

Equal outer documentary frames are identity-critical Scene geometry. They create a measurable inspection sequence while each inner source box preserves ratio/fit intent. Frame paper colour is a narrow material token that must later be resolved against approved Look; it is not exposed as a Scene palette control.

The following stay outside the Scene:

- table colour or texture;
- lighting falloff;
- vignette or halo;
- grain/noise;
- decorative shadow;
- source colour processing;
- global frame radius/Look theme unless a later common contract owns it.

## Forbidden regressions

- inherited central-renderer brightness/filter on non-focused cards;
- active glow over artwork;
- card opacity used for edge fading while visible;
- hidden duplicated source elements for looping;
- table paper or texture leaking into alpha-zero pixels;
- captions changing source crop;
- registration lines drawn through source pixels at full opacity.
