# Scene DNA — Focus Strip

## Irreducible identity

**Fixed station + ordered strip + measured scan stops.** Remove any one and the Scene collapses into a carousel, ticker, or static row.

## Memorable still

Equal documentary frames cross one planar axis. One frame is exactly registered beneath four corner marks and a cross-axis rule. Adjacent ordered frames remain visible as sequence context. Indices/captions identify the working edit.

## Memorable movement

The station never moves. The strip advances one source interval, eases to zero, holds for inspection, then advances again. Each ID follows the same ordered track. Selection is a small physical lift at the station, never source dimming.

## Topology

- One-dimensional circular logical track.
- One source identity per track slot; no duplicate loop deck.
- Guaranteed offstage wrap half.
- Horizontal landscape/square/4:5 apparatus.
- Vertical 9:16 inspection column.
- Stable source order, failed slots, labels, and station semantics.

## Material logic

Documentary outer frame, registration corners, station rule, index, and caption. These are editorial apparatus, not a simulated glowing table. Source pixels remain untouched. The clean candidate has no scene-owned table ground, light, texture, grain, vignette, or filter.

## Temporal signature

`hold → one-slot travel → hold`, with zero-velocity arrivals. Directed rhythm compiles source-level stops as quick, quick, regular, quick. The final travel returns to source one through the same offstage track, producing an exact seam.

## Source roles

Every source is an equal ordered document. The active source temporarily occupies the inspection station. Failed sources remain documents with a visible failure placeholder. No source becomes a permanent hero; source order is never changed to privilege one frame.

## Source-count signatures

- 1: one still frame in station.
- 2: same-direction circular scan with long offstage return.
- 6–12: primary editorial strip.
- 24: bounded long sequence; all identities evaluated, only stage-adjacent frames mounted later.

## Canvas signatures

- Landscape: horizontal strip, vertical crosshair at station.
- Portrait: vertical column, horizontal crosshair at station.
- Square and 4:5: horizontal unless height/width exceeds the explicit portrait threshold.

## Essential controls

Frame size, gap, station position, focus lift, labels. Every other visual property belongs to Project frame intent, Look, or product-wide accessibility.

## Neighbour exclusions

### Versus Quiet Carousel

Quiet Carousel continuously carries sources through a calm focus well with modest depth. Focus Strip is planar, indexed, station-measured, and stop-start. It has equal documentary frames, explicit inspection holds, and registration apparatus. It must remain recognisable with all colour and captions removed.

### Versus Filmstrip River

Filmstrip River is material ribbon continuity. Focus Strip is a sequence of discrete documents that stop one-by-one under a fixed station.

### Versus Contact Sheet

Contact Sheet shows the whole ordered set at once; only attention marks move. Focus Strip exposes a bounded local neighbourhood and physically advances the sequence.

## Delete-to-test

- Delete the station: identity fails.
- Delete scan stops: becomes a carousel/ticker.
- Delete stable indices/order: editorial trust fails.
- Add source dimming/filter: source-fidelity contract fails.
- Make 9:16 a tiny horizontal row: canvas identity fails.
