# Contact Sheet isolated prototype

Dependency-free clean-room evaluator and generated-fixture browser/raster study. It does not import Product code, network media, historical assets, dependencies, or a shared family engine.

```sh
node prototype/verify.mjs
node prototype/capture.mjs
```

Open `prototype/index.html` through any local static-file server for play, pause, scrub, automatic/fixed/directed modes, Reset, canonical canvas ratios, reduced motion, source-count fixtures, keyboard selection, and debug reading-order geometry. Preview and fixed-step capture call `prototype/evaluator.mjs`.

The opaque paper/contact surface is identity-critical. Transparent output is deliberately unavailable and is not simulated. No Product integration or human verdict is claimed.
