# Scene DNA — The Hang

## Memorable outcome

A set of framed works descends from fixed upper anchors, receives one travelling disturbance, and becomes still through visible damping.

## Silhouette signature

Still:

- points/rail above;
- straight wires of deliberately unequal lengths;
- frames suspended below, not resting on a surface;
- negative space formed by length variation;
- one or two upper rails depending on canvas/count.

Playback:

- vertical descent from anchors;
- coherent pendulum arcs around fixed pivots;
- a shared delayed impulse;
- decreasing amplitude;
- final stillness and continuous return.

## Topology

`fixed upper pivots + variable wire lengths + shared damped pendulum field`

It cannot become a scatter layout because every x/y state is derived from a pivot, length, and angle. It cannot become the historical wall/pile concept because no frame starts in a bottom pile or flies to a wall slot.

## Invariants

1. Pivot identity and position never change during a compiled phrase.
2. Wire length identity never transfers between sources.
3. Angle derives from explicit period, phase delay, amplitude, and damping.
4. Collision headroom bounds frame size and swing.
5. No perpetual oscillation remains after finale restraint.
6. One source is restrained and weighty.
7. Failed sources keep their suspension geometry.
8. Source treatment stays 1/none/normal.
9. Transparent empty pixels remain colourless.
10. Evaluated work is bounded at ten.

## Anti-goals

- bottom pile to contact wall;
- independent random wobblers;
- physics integration dependent on frame rate;
- perpetual CSS keyframe sway;
- collision response chaos;
- scatter cards with decorative wires;
- source glow/dimming;
- camera zoom finale.

## Deletion test

Deleting this directory removes the suspended study without changing either scatter Scene or Product. No shared physical-motion primitive is earned yet.
