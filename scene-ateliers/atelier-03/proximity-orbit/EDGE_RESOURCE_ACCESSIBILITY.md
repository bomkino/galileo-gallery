# Edge, resource, and accessibility contract — Proximity Orbit

## Count policy

| Count | Behavior |
| ---: | --- |
| 0 | explicit empty stage |
| 1 | static near presentation; no fake travel |
| 2 | opposite near/far pair |
| 3–20 | all stable path phases |
| 21–127 | 16-source cyclic near window with far guard entry/exit |

No source pops, duplicates, or changes order. Full count remains disclosed.

## Budgets

- evaluated identities: maximum 127;
- mounted cards: maximum 20 ordinary, 16 large-set;
- full-resolution preview decodes: near + two shoulders, maximum 3;
- active preview video decoders: maximum 2;
- hidden duplicates: 0;
- prototype network/workers/observers/intervals/persistent state/GPU contexts: 0.

## Collision and ratios

Compute actual width/height after ratio, then cap near scale against horizontal and vertical safe bounds. Do not change ratio, hide near source, alter path order, or use lighting to disguise clipping. Portrait applies stricter height cap.

## Failed/video

Failed card remains eligible for near hold with neutral placeholder. Video suspension in far preview preserves target story time and pose; Product seeks deterministically before readable near passage.

## Offscreen/remount/disposal/context loss

Offscreen scheduling may stop without mutating phase. Remount evaluates current explicit time; no mount entry. Disposal removes preview scheduler/listeners and releases renderer/media/context. Fallback uses same 2D positions/scales/z or static reduced-motion arrangement.

## Reduced motion

Static near source with fixed far context; no entry, orbit, swell interpolation, spotlight travel, or exit. Video behavior follows Product reduced-motion/media settings.

## Keyboard/focus

- one stage group tab stop;
- Left/Right previous/next source inspection;
- Home/End first/last;
- Enter/Space detail; Escape restore;
- announce “Near card n of total: title” after settle;
- source-order focus independent of z-order;
- visible outline outside artwork, alpha-safe.

Hover may highlight identification only. It cannot change phase, velocity, scale, alpha, or serialization.

## Fallback ladder

1. projected card planes from pure evaluator;
2. DOM/SVG 2D positions/scales/z;
3. reduced-motion static near/far composition;
4. ordered list.

## Unsupported

Spatial axis, hover/pointer/scroll output motion, source lighting, nested rings, card tumble, ambient flourish, and Scene-owned audio.

## Final gauntlet lifecycle and authoring corrections

- Maximum mounted cards for the 127-source fixture: 16; every canonical checkpoint records a positive bounded count.
- Mounted DOM nodes are keyed by source ID and reused across frames. Only sources leaving the bounded window are removed. Visual z-order never changes DOM/focus order.
- The preview owns one `requestAnimationFrame` chain, cancels it on pause/reset/edit, and pauses when the document is hidden. Repeated Play → Pause → Play cannot multiply schedulers.
- Fixed duration, reduced motion, and featured-source inspection are visible controls. System reduced-motion preference initializes the checkbox unless explicitly overridden.
- Human-facing source numbers are one-based; serialized evaluator indices remain zero-based.
- Stage help is associated through `aria-describedby`; status updates are polite and atomic; generated cards form a labelled group; static HTML control bounds match evaluator bounds.
- Final raster evidence zeroes matte RGB under alpha zero before hashing and records the exact sanitized count/reason. This is evidence-pipeline truth, not a Product-export claim.
- A Chromium headless attempt did not establish a functional page session in this runner. Browser focus traversal, accessibility-tree capture, heap/remount, and Product-renderer lifecycle remain unclaimed.


## Applied authoring interaction and history boundary

- The visible story source field is serialized Scene intent.
- Arrow/Page/Home/End inspection uses a separate ephemeral source index.
- Escape clears inspection or cancels an active card scrub.
- Unmodified primary-pointer card drag scrubs review time through one coalesced animation frame.
- Continuous control edits commit one undo record; scrub, play, inspection, pointer capture, DOM,
  and diagnostics never enter history.
- A deterministic review URL round-trips bounded prototype controls and time but is explicitly not
  a Galileo Project.
- Runtime diagnostics disclose card creates/removals/reuses, scheduler frames, maximum mounted
  nodes, history depth, and inspection state without becoming evaluator input.
