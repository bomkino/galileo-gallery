# Resource and lifecycle observation — Dealer's Pick

The evaluator calculates continuous fractional focus against all ordered identities, then emits the configured seven-card nearest window. The ordinary five-source study mounts five; the 127-source study evaluates 127 and mounts seven. Canonical checkpoints retain a bounded mount count and repeated SVG/PNG rendering produces the same hash.

The HTML preview uses `requestAnimationFrame` only to advance explicit preview `timeMs`. Scrub, vectors, fixed-step evidence, and export-facing design invoke the same pure evaluator. The prototype owns no network request, persistent store, observer, worker, WebGL context, texture, or media decoder.

A Chromium headless attempt did not establish a functional page session in this runner and was terminated. Browser focus traversal, DOM remount, heap stability, Product decode, context loss, and disposal remain unintegrated and unclaimed.

The final prototype keeps source-ID-keyed DOM nodes stable, owns one single cancellable preview scheduler, pauses it when hidden, and exposes reduced motion/fixed duration/source inspection visibly. The evaluator remains stateless and reconstructible from config, ordered media, stage, and explicit story time.
