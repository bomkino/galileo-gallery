# Scene DNA — Deck River / Continuous

## Fingerprint

**Silhouette:** small frames converge near a fixed horizon, enlarge through one lateral near pass,
then shrink into a second depth lane.

**Real-speed read:** camera stays still; frames circulate through an architectural corridor.

**Material:** framed works moving through a gallery passage, not cards scaling on a flat track.

## Non-negotiable grammar

- One fixed camera and horizon.
- One closed world centreline.
- Distinct approach, near passage, recede, and offstage far return.
- Constant arc-length source spacing.
- Projection geometry supplies depth.
- Camera-facing readable artwork.
- No source treatment by distance.

## Forbidden drift

- Flat constant-size travel: Quiet Carousel.
- Open path that resolves into a hero: Chapter Reveal.
- Two planar lanes with no perspective: Filmstrip.
- Sinusoidal transverse baseline: Wave.
- Generic translateZ and wrap: carousel with fake depth.
- Random lane table, roll, wag, bob, haze, dimming, or focus brightness.

## Source roles

| Region | Role |
| --- | --- |
| Far approach | Establish source order and corridor horizon. |
| Middle approach | Make increasing screen velocity causally legible. |
| Near passage | Closest readable frame; never a hero takeover. |
| Recede | Preserve identity after passing the viewer. |
| Far return | Recycle beyond visible depth with continuous tangent. |

## Key poses

| Phase | Expected silhouette |
| ---: | --- |
| `0.00` | One near passage, two depth chains, far return absent. |
| `0.25` | Approach lane dominates; recede remains visible. |
| `0.50` | Opposite source owns near passage; camera unchanged. |
| `0.75` | Reverse visual balance; same corridor. |
| `1.00` | Exact position/tangent/velocity seam. |

## Distinctness threshold

Pass only when black-card stills reveal a depth corridor and playback reveals approach–pass–recede
without relying on colour, opacity, labels, or background architecture.
