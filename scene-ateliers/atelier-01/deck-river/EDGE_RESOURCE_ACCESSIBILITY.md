# Edge, resource, and accessibility policy — Deck River / Continuous

## Edge behavior

- 0: empty fixed camera-world.
- 1: one complete corridor circulation with a long hidden return.
- 2: half-cycle separation.
- 3–12: preferred readable traffic.
- 13–256: equal arc spacing remains deterministic; visible-depth/canvas culling bounds later mounting.
- Mixed ratios keep source dimensions. Failed sources retain path identity. Video time stays global.

Portrait contracts lateral projection and moves the horizon; it does not rotate a landscape DOM. Near plane, camera clearance and visible depth are hard bounds.

## Motion safety

No camera roll/dolly, blur, random sway, opacity depth or brightness depth. Frames remain camera-facing. Human review must still decide nausea comfort, text readability and maximum useful density.

## Accessibility and reviewer UX

Every geometry control has a reviewer-facing label and live numeric output. Named poses, silhouette, composites, exact scrub, Reset and reduced motion are keyboard reachable. Animated status is not an ARIA live stream. Reduced motion pauses transport and selects five static corridor landmarks.

## Resource/lifecycle

The 768-sample arc table and frame state are bounded per evaluation. A future renderer should memoize the table by validated parameters, mount only visible sources plus guard, pause hidden decodes, cancel callbacks and dispose graphics/media resources. Evidence is a bounded full-cycle observation, not a production soak.
