# Isolated prototype

Dependency-free generated-fixture study for the candidate `wave-ticker` charter. It is not imported by Galileo Gallery and contains no Product implementation.

The evaluator closes its metric track at an integer number of requested wavelengths, so position and first derivative meet at the seam. Cards travel along the fixed path; no card receives random phase or bob.

Run: `node check.cjs`. The evidence runner inlines the same prototype bytes because managed Chromium blocks `file://` and local listening sockets.
