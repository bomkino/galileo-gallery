# Edge, resource, and accessibility policy — Ribbon / Wave

## Edge behavior

- 0: empty path.
- 1/2: bounded repeated render instances keep the path populated without inventing media identities.
- 3–256: stable ordered metric track and bounded instance count.
- Portrait uses a vertical major axis; the wave bends horizontally.
- Failed/video/soft-alpha frames keep ratio, order and clean pixels.

High amplitude plus short wavelength can overlap or over-rotate cards. The ±10° tangent cap protects typography, but human review still owns comfort and density.

## Accessibility and reviewer UX

The workbench exposes Frame size, Minimum gap, Amplitude, Wavelength and Tangent follow with numeric output; Reset; named phases; scrub; canvas; direction; silhouette; composites; count and reduced motion. Animated status is not live. Reduced motion pauses transport and freezes deterministic wave landmarks.

## Resource/lifecycle

Repeated instances are capped at 48 per source. A future renderer mounts the visible window plus guard, reuses decodes, pauses hidden video, cancels callbacks and disposes contexts/media on unmount or context loss.
